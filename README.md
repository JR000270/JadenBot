# JadenBot

A feed-forward neural network chatbot built with PyTorch, using intent classification over a small set of predefined patterns and responses. Includes a Streamlit chat UI.

## How it works

1. `intents.json` defines a set of intents, each with example patterns (things a user might say) and possible responses.
2. `nltk_utils.py` tokenizes and stems input text, then converts it into a bag-of-words vector.
3. `model.py` defines a simple 3-layer fully connected `NeuralNet` (input → hidden → hidden → output).
4. `train.py` builds the training data from `intents.json`, trains the model, and saves the trained weights plus vocabulary/tag metadata to `data.pth`.
5. `chat.py` loads `data.pth` and the model, and exposes `get_response(message)` which classifies the input and returns a random response from the matched intent (or a fallback if confidence is below 75%).
6. `app.py` is a Streamlit front-end that wraps `chat.py` in a chat interface.

## Setup

```bash
pip install -r requirements.txt
```

The first run will download the NLTK `punkt_tab` tokenizer data automatically (via `nltk.download('punkt_tab')` in `nltk_utils.py`).

## Training

To (re)train the model after editing `intents.json`:

```bash
python train.py
```

This regenerates `data.pth`, which stores the model weights, vocabulary, and tags.

## Running the chatbot

**Streamlit web UI:**

```bash
streamlit run app.py
```

**Command line** (using `chat.py`'s `get_response` directly):

```python
from chat import get_response
print(get_response("Hello!"))
```

## Customizing responses

Edit `intents.json` to add new tags, patterns, and responses, then re-run `python train.py` to retrain the model.

## Project files

| File | Purpose |
|---|---|
| `intents.json` | Training data: intents, patterns, and responses |
| `nltk_utils.py` | Tokenization, stemming, bag-of-words helpers |
| `model.py` | `NeuralNet` architecture |
| `train.py` | Trains the model and saves `data.pth` |
| `chat.py` | Loads the trained model and generates responses |
| `app.py` | Streamlit chat interface |
| `data.pth` | Saved model weights + vocabulary (generated by `train.py`) |
